# Blueprint de 2x — Funil Hugo Miyazaki (VSL travada)

Base: auditoria de congruência (49/70 — Funcional) + VSL transcrita + 3 docs Clube da Conversão
(Pesquisa Profunda, Superprodução de VSLs, Plano por Blocos/42 blocos).

## Princípio-mestre
A **VSL faz a persuasão pesada** e não pode mudar. O trabalho das páginas é entregar o lead frio 45+
na VSL **já aquecido e congruente**, e fechar quem já assistiu. Cada página replica uma FASE dos 42 blocos
(Lead → História → Mecanismo → Solução/Desejo) pra o lead chegar no vídeo com a crença já instalada.

## Camada neuroquímica (interpretação do pedido "dopamina, ocitocina etc.")
| Neuro | Função | Onde aplicar |
|---|---|---|
| **Dopamina** | antecipação / recompensa / progresso | barra do quiz, open loops ("no próximo passo você descobre…"), revelação do diagnóstico |
| **Ocitocina** | confiança / vínculo / pertencimento | rosto do Hugo cedo, acolhimento ("não é culpa sua"), depoimentos com nome+cidade, "+10 mil pessoas como você" |
| **Serotonina** | status / validação | reframe "não é preguiça, não é fraqueza" (tira vergonha, dá status) |
| **Cortisol/Adrenalina** | aversão à perda / urgência | prognóstico, countdown, 100 vagas, custo de não agir |

Arco obrigatório (método): **tensão → esperança → ação**. Nunca fear→fear. Autoridade PROGRESSIVA (frio).
